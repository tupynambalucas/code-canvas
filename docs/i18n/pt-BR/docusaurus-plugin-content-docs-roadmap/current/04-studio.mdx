Esta seção cobre o ambiente Penpot, automação de sincronização de design-tokens e design de ativos de UI personalizados.

> [!WARNING]
> O workspace Studio foi reaproveitado de outro projeto. Ele precisa ser atualizado para se tornar específico do CodeCanvas (em vez do projeto anterior). Atualizações futuras são necessárias para limpar arquivos de ambiente, configurações de bucket e assets de design para refletir a marca do CodeCanvas.

## Marcos Concluídos

### Ambiente de Design Colaborativo

- **Hub de Design Self-Hosted**: Implantação de um ambiente conteinerizado do Penpot v2 (ambiente suportado por IA com Aide) no workspace `@codecanvas-studio/assets`, viabilizando o desenvolvimento local seguro de mockups visuais colaborativos.
- **Pacotes do Sistema de Design Centralizado**: Estruturação do `@codecanvas-studio/assets` para atuar como o pacote unificado de guia de estilo de marca, definições tipográficas, espaçamentos e tokens de paletas de cores.

### Pipeline de Ativos

- **Exportação de Ativos de Marca**: Padronização de ativos exportados (incluindo vetores SVG, marcas gráficas de logos e esquemas de cores) nos repositórios do projeto, disponibilizando templates puros para consumo das aplicações web.
- **Hospedagem de Ativos na Nuvem**: Implantação de um motor CLI de sincronização bidirecional de ativos sob `@codecanvas-studio/assets/bucket`, permitindo replicação direta de fontes de identidade visual e assets prontos para web com o Cloudflare R2 Object Storage, eliminando arquivos pesados do histórico do Git.

## Foco Planejado

- **Integração de Sincronização**: Sincronizar automaticamente tokens do Penpot diretamente para o código-fonte.
- **Ativos de Suíte Expandidos**: Criação de bibliotecas de ativos de marketing e de interface personalizadas.
