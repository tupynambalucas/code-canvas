# Referência de Comandos

Este documento serve como a **Única Fonte da Verdade** (Single Source of Truth) para todo comando CLI, script PNPM, comando Docker e instrução de orquestração usados no monorepo CodeCanvas.

## Monorepo Orchestration

Scripts usados para gerenciar dependências, limpeza e tarefas no nível do workspace.

- **`pnpm install`**: Instala todas as dependências no monorepo.
- **`pnpm install --frozen-lockfile`**: Instala dependências estritamente a partir do `pnpm-lock.yaml` (usado em CI/CD).
- **`pnpm project:clear`**: Limpa todos os `node_modules` e caches de build usando `npkill`.
- **`pnpm add <package> --catalog`**: Adiciona um pacote ao catálogo compartilhado do PNPM.
- **`pnpm add <package>@catalog: --filter <app-name>`**: Instala um pacote catalogado em um workspace específico.

## Validation & Quality

Scripts para garantir a qualidade do código e a tipagem estrita.

- **`pnpm typecheck`**: Executa validação paralela do TypeScript em todas as workspaces via Turborepo.
- **`pnpm lint`**: Executa validação do ESLint em todas as workspaces.
- **`pnpm build`**: Compila um build de produção para todas as workspaces.
- **`pnpm --filter @codecanvas/extension build`**: Faz o build apenas da extensão.
- **`pnpm test`**: Roda os testes em todas as workspaces.

## Extension

Comandos específicos para o contexto da `@codecanvas/extension`.

- **`pnpm --filter @codecanvas/extension watch:build`**: Inicia o esbuild watcher para desenvolvimento rápido.
- **`pnpm --filter @codecanvas/extension test`**: Roda os testes da extensão dentro de um VS Code Host.

## Documentation

Comandos para a Docs em Docusaurus (`docs/`).

- **`pnpm docs:dev`**: Inicia o servidor local de desenvolvimento do Docusaurus com HMR.
- **`pnpm docs:build`**: Compila a documentação em HTML/CSS estático para produção.
- **`pnpm docs:generate:changelog`**: Gera o `CHANGELOG.md` raiz com base nas releases.
- **`pnpm docs:generate:roadmap`**: Gera o `ROADMAP.md` raiz com base no roadmap.

## Studio & Tools

Comandos para design e agentes de IA.

- **`pnpm --filter @codecanvas-studio/themes build`**: Compila os temas JSON e integra com o vscode.
- **`pnpm --filter @code-canvas/tools ...`**: (Comandos de automação).

## Git & Version Control

Fluxos de trabalho para branching, commits e releases.

- **`git checkout -b feature/<name>`**: Inicia uma nova branch de feature.
- **`pnpm version:changeset`**: Gera um arquivo de changeset para rastrear incrementos de versão e changelogs.

## Docker & Infrastructure

Comandos diretos da CLI do Docker para depuração e manutenção.

- **`docker ps`**: Lista os containers em execução para os agentes da cli.
- **`turbo prune`**: Executa o prune do workspace do monorepo para builds minimalistas no Docker.
