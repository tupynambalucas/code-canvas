# CodeCanvas Project

CodeCanvas é uma extensão avançada e de alto desempenho para o Visual Studio Code, desenvolvida para transformar completamente o ambiente de desenvolvimento através de personalizações profundas de UI, injeção de CSS e manipulação do DOM.

_"Assuma o controle total do seu editor. A extensão CodeCanvas permite modificações avançadas na UI, possibilitando que você personalize seu ambiente de código com fundos dinâmicos impressionantes e integração automática de temas."_

## 1. Visão Geral do Produto e Proposta de Valor

Antes do CodeCanvas, personalizar a UI do VS Code era severamente limitado por:

- **Sandbox Estrito:** O modelo de segurança padrão do VS Code impede modificações arbitrárias no CSS ou no DOM.
- **Temas Estáticos:** Temas padrão permitem apenas mudanças básicas de tokens de cores, sem suporte para verdadeiros fundos dinâmicos ou layouts complexos.
- **Configuração Manual:** Alcançar configurações avançadas exigia a aplicação manual de patches e gambiarras instáveis.

Nós transformamos esse processo em um fluxo de trabalho profissional e automatizado:

| Funcionalidade | Descrição |
| :--- | :--- |
| **Liberdade e Personalização** | Injete CSS e manipule o DOM do VS Code sem restrições. |
| **Fundos Dinâmicos** | Suporte para fundos independentes no editor, barra lateral, painel e barra secundária. |
| **Integração Automática de Temas** | Mude seu tema do VS Code e veja como os fundos e configurações são aplicados automaticamente em tempo de execução. |

### Público-Alvo

1. **Power Users & Desenvolvedores:** Desenvolvedores que desejam uma experiência de IDE altamente customizada, esteticamente agradável e personalizada.
2. **Designers e Criadores de Temas:** Criativos buscando construir temas ricos e dinâmicos que vão além de simples mudanças de cores.

## 2. Fluxograma Operacional

A extensão CodeCanvas orquestra o seguinte fluxo operacional:

1. **Descoberta do Core:** A extensão localiza o caminho de instalação local do VS Code e o arquivo principal da UI (`workbench.desktop.main.js`).
2. **Injeção (Patching):** Um script (`codecanvas.js`) e uma folha de estilos (`codecanvas.css`) são injetados persistentemente no HTML interno do editor.
3. **Elevação de Privilégios:** Se necessário (em diretórios protegidos do Windows/Linux), a extensão solicita privilégios administrativos via `@vscode/sudo-prompt`.
4. **Configuração em Runtime:** A extensão expõe propriedades (`codecanvas.enabled`, `codecanvas.ui`) e observa mudanças de tema em tempo real.
5. **Sincronização de Tema:** Quando o tema ativo muda, o CodeCanvas lê a propriedade `backgroundConfig` do JSON do tema e aplica automaticamente os novos estilos, opacidades e imagens de fundo.

## 4. Foco Estratégico

Nossa prioridade atual é a **entrega perfeita da extensão independente do VS Code (`@codecanvas/extension`)**.

### Principais Funcionalidades

- **Runtime Patching:** Modificações seguras e reversíveis no núcleo do VS Code.
- **Studio Themes:** Uma coleção de temas curados e dinâmicos gerados pela workspace Studio (`@codecanvas-studio/themes`).
- **Automação com IA:** Servidores especializados em Model Context Protocol (MCP) e scripts de infraestrutura na workspace Tools (`@code-canvas/tools`) para aumentar a produtividade do desenvolvedor.

## 5. Início Rápido

Certifique-se de ter o **Node.js 22+** e o **PNPM 11+** instalados.

1.  **Instale as Dependências:**

    ```bash
    pnpm install
    ```

2.  **Inicie o Desenvolvimento Local:**
    Fornecemos scripts de orquestração unificados via Turborepo para compilar e testar a extensão.

    Consulte a [Referência de Comandos](./commands-reference.mdx) para instruções sobre como iniciar a stack (`pnpm build`), rodar validações ou realizar deploys.
