# CodeCanvas Project

CodeCanvas is an advanced, high-performance extension for Visual Studio Code designed to completely transform the development environment through deep UI customizations, CSS injection, and DOM manipulation.

_"Take full control of your editor. The CodeCanvas extension enables advanced UI modifications, allowing you to personalize your coding environment with stunning dynamic backgrounds and automated theme integration."_

## 1. Product Overview & Value Proposition

Before CodeCanvas, customizing the VS Code UI was severely limited by:

- **Strict Sandbox:** VS Code's default security model prevents arbitrary CSS or DOM modifications.
- **Static Themes:** Standard themes only allow basic color token changes, lacking support for true dynamic backgrounds or complex layouts.
- **Manual Configuration:** Achieving advanced setups required manual patching and brittle hacks.

We transform this process into a professional, automated workflow:

| Feature | Description |
| :--- | :--- |
| **Freedom & Customization** | Inject CSS and manipulate the VS Code DOM without restrictions. |
| **Dynamic Backgrounds** | Support for editor, sidebar, panel, and secondary bar independent backgrounds. |
| **Automatic Theme Integration** | Change your VS Code theme and watch as backgrounds and configurations are automatically applied in runtime. |

### Target Audience

1. **Power Users & Developers:** Developers who want a highly customized, aesthetically pleasing, and personalized IDE experience.
2. **Designers & Theme Creators:** Creatives looking to build rich, dynamic themes that go beyond simple color changes.

## 2. Operational Flowchart

The CodeCanvas extension orchestrates the following operational flow:

1. **Core Discovery:** The extension locates the local VS Code installation path and the main UI file (`workbench.desktop.main.js`).
2. **Injection (Patching):** A script (`codecanvas.js`) and a stylesheet (`codecanvas.css`) are persistently injected into the editor's internal HTML.
3. **Privilege Escalation:** If required (on Windows/Linux protected directories), the extension requests administrative privileges via `@vscode/sudo-prompt`.
4. **Runtime Configuration:** The extension exposes properties (`codecanvas.enabled`, `codecanvas.ui`) and observes theme changes in real-time.
5. **Theme Synchronization:** When the active theme changes, CodeCanvas reads the `backgroundConfig` property from the theme's JSON and automatically applies the new styles, opacities, and background images.

## 4. Strategic Focus

Our current priority is the **perfect delivery of the standalone VS Code Extension (`@codecanvas/extension`)**.

### Key Features

- **Runtime Patching:** Safe and reversible modifications to the VS Code core.
- **Studio Themes:** A collection of highly curated, dynamic themes generated by the Studio workspace (`@codecanvas-studio/themes`).
- **AI Automation:** Specialized Model Context Protocol (MCP) servers and infrastructure scripts in the Tools workspace (`@code-canvas/tools`) to enhance developer productivity.

## 5. Quick Start

Ensure you have **Node.js 22+** and **PNPM 11+** installed.

1.  **Install Dependencies:**

    ```bash
    pnpm install
    ```

2.  **Start Local Development:**
    We provide unified orchestration scripts via Turborepo to build and test the extension.

    See the [Command Reference](./commands-reference.mdx) for instructions on starting the stack (`pnpm build`), running validations, or deploying to production.
